# ShopNexa — New Design

This release replaces the previous visual direction with a clean retail command-center UI:
- Light workspace with deep navy navigation
- Compact, high-density tables inspired by modern financial dashboards
- Decision-first KPI cards
- Consistent primary/secondary actions
- Responsive sidebar-to-mobile navigation
- Restrained color: blue for actions, green/red only for status
- Existing application routes, database, authentication and business logic preserved

Design direction researched against current 2026 dashboard patterns: Linear/Vercel restraint, Stripe-style data tables, and retail dashboards focused on sales, inventory and staff performance.


### Automatic product artwork
Product artwork is generated by ShopNexa from each product name. No product-image folder needs to be copied to GitHub. The server automatically selects an appropriate illustrated category and generates the SVG at `/product-image?name=...`.
